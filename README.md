## PALINDROMOS

## 📌Descrição:
Essa atividade resolve o problema de encontrar números menores que um valor informado que são palindromos em duas bases diferentes:
- Base 10 (decimal)
- Base 2 (binário)

Após encontrar esse números, ele realiza a soma de todos eles.

## Caminhos na Rede

## 📌Descrição:
Essa atividade calcula a quantidade de caminhos possíveis para atravessar uma grade quadrada, partindo do canto superior esquerdo até o canto inferior direito.

O movimento permitido é apenas:

- ➡️ Direita
- ⬇️ Baixo

O objetivo é descobrir quantas combinações de movimentos diferentes existem para chegar ao destino.


## Numero primo 

## 📌 Descrição:
Essa atividade tem como objetivo encontrar o **n-ésimo número primo**.

O programa verifica quais números são primos e conta a quantidade encontrada até chegar na posição desejada. Ao final, retorna o número primo correspondente.
